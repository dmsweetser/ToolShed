Which version of Uniswap to use for trading. V3 has the most tokens and activity.
v3

Trading Budget

STARTING_ETH
How much ETH you're starting with. $10 is about 0.0033 ETH when ETH is at $3000.
0.0033 ETH
TRADE_AMOUNT_PERCENT
What percentage of your budget to use for each trade. 10% of $10 = $1 per trade.
10%
MIN_TRADE_AMOUNT_ETH
Never trade below this amount. Prevents trading with amounts that aren't worth the fees.
0.00001 ETH
MAX_TRADES
How many trades can be open at the same time. Limits exposure to any single token.
3
TRADE_COOLDOWN
Minimum seconds to wait before trading the same token again. Prevents rapid buying/selling.
60 seconds

Opportunity Finder

MIN_PRICE_CHANGE
How much a price needs to move (percentage) before the system pays attention.
1.0%
MIN_TIME_WINDOW
How long a price movement must take to be considered (in seconds).
10 seconds
MAX_TIME_WINDOW
The longest time a pattern can take to form (in seconds).
300 seconds
MIN_OCCURRENCES
How many times a pattern must appear before trading on it.
2

Opportunity Quality

MIN_WIN_RATE
Only use patterns that have worked this often in testing (percentage).
60%
BACKTEST_PERIOD
How much past price history to use when testing patterns (in hours).
24 hours
TARGET_PROFIT_PERCENT
Sell when the trade makes this much profit (percentage).
1.0%
MIN_PROFITABILITY
Only use patterns that have made at least this much profit on average in testing.
1.5%
MAX_PATTERNS_PER_TOKEN
How many different patterns to track for each token.
5

Safety

MAX_SLIPPAGE
Maximum price change allowed when executing a trade. Prevents bad trades when prices move fast.
0.5%
MIN_PROFIT_PERCENT
Don't close a trade unless it's made at least this much profit.
0.5%

If a trade hasn't hit your profit target by this time, sell it anyway (in seconds).
600 seconds
MAX_GAS_PRICE
Don't trade if network fees are higher than this (in gwei).
200 gwei
GAS_LIMIT
Estimate of how much computational work each trade requires.
200000
PREVENT_SEQUENTIAL_TRADES
Prevents buying and selling the same token too quickly in a row, which can lose money to fees.
true
