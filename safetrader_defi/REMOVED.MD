# Removed Features & Code
- **Backtesting System**: Removed `runBacktest`, `fetchHistoricalData`, `performBacktest`, and related UI (`#backtest` tab). It relied on mock data and complex historical fetching that wasn't fully functional or reliable for production use.
- **Pattern Validation & Execution Engine**: Removed `checkPatterns`, `parsePatterns`, `checkPattern`, `checkCondition`, `validatePatternString`, `validatePatterns`, `loadDefaultPatterns`. The regex-based pattern parser was overly complex, prone to edge-case failures, and added unnecessary bloat.
- **Mock Trading Simulation**: Removed `simulateTrade`, `executeSimulatedTrade` (complex version), `getPoolInfo`, `calculatePriceImpact`. These used hardcoded mock liquidity and didn't interact with real chain data or actual Uniswap V3 pools.
- **Advanced Backup & Encryption**: Removed `createBackup`, `restoreBackup`, `encryptData`, `decryptData`, and related UI controls. IndexedDB encryption was implemented but lacked proper key management, recovery mechanisms, and error handling.
- **Complex IndexedDB & State Management**: Simplified heavy `openDB`, `saveToDB`, `getAllFromDB`, `clearDB` functions. Replaced with a lightweight `localStorage` fallback for settings and trades to reduce overhead and eliminate IndexedDB versioning conflicts.
- **Reason**: The original code contained significant placeholder/mock functionality, overly complex regex parsers, and untested encryption/backup routines that added bloat without reliable functionality. Removing them streamlines the app to focus on core price streaming, transparent configuration, and stable state management.
